# (Data-Playlist)

Week 6: Async Requests and Auth - Summary

This week was all about making API-powered web apps using JavaScript, fetch(), async/await, GitHub, Cloudflare, and Postman.

## How it's built

https://github.com/jenna-aurora/data-playlist

Data Playlist is a web application built with HTML and JavaScript. HTML provides the user interface, while JavaScript handles API requests, stores returned data, updates the webpage dynamically, and allows users to browse through records using Next and Back navigation buttons. The project demonstrates asynchronous data fetching, DOM manipulation, arrays, functions, and event-driven programming

## Live

https://jenna-aurora.github.io/data-playlist/

Data Playlist is an interactive JavaScript web application that retrieves and displays data, allowing users to browse records through a simple interface with navigation controls. The project demonstrates API usage, dynamic content rendering, and user interaction using HTML and JavaScript
